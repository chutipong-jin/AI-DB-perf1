CTE payment_summary 
payment_summary AS (
    SELECT ss.store_code, ss.sale_schedule_date,
           SUM(CASE WHEN rcpm.payment_type = $20 THEN (rcpm.amount - rcpm.change) ELSE $21 END) AS cash_payment_amount,
           …   -- อีก 6 ประเภทการชำระ
    FROM pos_mgr.sale_schedule ss
    INNER JOIN pos_mgr.receipt rc ON rc.sale_schedule_id = ss.id              -- ไม่มี partition_date
    LEFT JOIN pos_mgr.receipt_payment rcpm ON rcpm.receipt_no = rc.receipt_no  -- join ด้วย receipt_no อย่างเดียว
    WHERE ss.sale_schedule_date = $6 AND ss.store_code = $7
    GROUP BY ss.store_code, ss.sale_schedule_date
)

Query เต็มมี 7 CTE (pg_stat_statements queryid -4225865709950654903, Query Insights hash 16617368465228759625) แต่ CTE อื่นมีต้นทุนรวมกันไม่ถึง 1% ของ plan

สาเหตุ

1. Join receipt_payment ด้วย key ไม่ครบ

  • receipt_payment เป็น partitioned table แบ่งรายเดือนด้วย partition_date (36 partition, ~19.5M rows, 7.7 GB)
  • index ที่มีคือ PK (partition_date, store_no, receipt_no, item_no) และ (partition_date, store_no, receipt_no) ไม่มีตัวไหนขึ้นต้นด้วย receipt_no
  • เมื่อ join ด้วย receipt_no อย่างเดียว planner จึงเลือก Parallel Seq Scan ทุก partition แล้วสร้าง hash table จาก ~19.5M rows เพื่อใช้แค่ ~200 rows
  • seq_tup_read สะสมของ receipt_payment อยู่ที่ 1.24 ล้านล้าน rows

2. ไม่ตัด partition ของ receipt

  • receipt ก็เป็น partitioned table รายเดือน (36 partition, 41 GB)
  • join ด้วย sale_schedule_id อย่างเดียว จึงต้อง probe index ทั้ง 36 partition
  • ส่วนนี้ยังเร็ว เพราะมี index sale_schedule_id แต่ทำให้ส่ง partition_date ต่อไปยัง receipt_payment ไม่ได้

ข้อควรระวังตอน implement

  • ใช้ช่วง :date ถึง :date + 1 ห้ามใช้ = เพราะมีใบเสร็จหลังเที่ยงคืนที่อยู่ partition วันถัดไป
  • ถ้า parameter วันที่ถูก bind เป็น varchar หรือ timestamp ให้เขียน CAST(:saleScheduleDate AS date) + 1
  • เงื่อนไขบรรทัดสุดท้ายของ rcpm ไม่บังคับ ช่วยลด planning time จาก ~19 ms ให้ planner ไม่ต้องพิจารณาทั้ง 36 partition
  • ก่อน deploy ให้เทียบ count และ SUM ระหว่างแบบเดิมกับแบบใหม่บน staging หรือ replica อย่างน้อย 2–3 สาขา รวมวันที่มีใบเสร็จหลังเที่ยงคืน
